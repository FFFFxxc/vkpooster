# VK Reposter Pro 4.2 Safe

Версия объединяет последовательный постинг, отложенные комментарии и Истории,
безопасную очистку сообществ и загрузку Клипов через одну видимую вкладку VK.

## Что изменено

- полностью удалены cookie-вход, `web_token`, Kate Mobile OAuth и подмена
  заголовков;
- удалены автолайки, мультиаккаунт-накрутка, TwiBoost и скрытый параллельный
  clips uploader;
- пользовательский токен хранится только в `chrome.storage.local`;
- при первом переходе с v3 старые Kate/VKHost-токены очищаются и не
  подхватываются автоматически;
- пользовательские аккаунты/токены больше не синхронизируются с сервером;
- для каждой целевой группы можно задать отдельный токен сообщества;
- в режиме копирования каждая фотография сначала загружается заново именно в
  целевое сообщество: просмотрщик VK больше не показывает паблик-источник;
- публикации идут строго последовательно с интервалом не менее 1,2 секунды;
- для `wall.post` используется `random_id`, поэтому безопасный retry не создаёт
  дубликат после потерянного ответа;
- CAPTCHA, validation, flood-control и suspicious-activity ставят очередь на
  паузу до ручного продолжения;
- отложенные посты создаются нативным `publish_date` VK;
- сервер хранит токены сообществ только в AES-256-GCM шифротексте и выполняет
  отложенные комментарии с интервалом;
- Клипы передаются прямо между страницей расширения и одной обычной вкладкой
  VK по 128 КБ; файл, cookies и сессия не попадают на Render;
- Истории используют токен конкретного сообщества, временный GridFS-файл до
  25 МБ и официальный Stories API; файл удаляется после успеха или отмены;
- очистка стен и альбомов сначала показывает точный предпросмотр и затем удаляет
  по одному объекту с живым прогрессом, итоговыми счётчиками и кнопкой остановки;
- удаление фотографий ограничено защитной квотой: не более 950 успешных удалений
  на один паблик за скользящие 24 часа. Счётчик хранится локально отдельно для
  каждого сообщества; лишние фото остаются для следующего запуска, а окно
  предпросмотра показывает их число и время освобождения новых мест;
- если VK раньше вернёт flood-control или rate limit, только затронутый паблик
  получает дополнительную локальную паузу (15 минут для краткого ограничения,
  24 часа для flood/rate limit); записи стены без удаления фото можно продолжать
  очищать отдельно;
- на странице отложки появилась единая «Очистка данных»: отдельно удаляются
  ошибки, успешно завершённые записи или вся завершённая история. Активные
  задания сохраняются, а серверная очистка действительно удаляет документы
  комментариев/Историй из MongoDB и оставшиеся медиа Историй из GridFS;
- общая страница отложки показывает карточки с сохранёнными превью постов,
  комментариев, Историй и Клипов без массового опроса VK при открытии.
- активные посты в отложке сортируются от ближайших к дальним, завершённые — от
  новых к старым; вкладка «История» содержит кэшируемую аналитику и рейтинг
  настроенных групп по активности за 7/30 дней или последние 100 записей.

## Быстрый запуск расширения

1. Откройте `chrome://extensions`.
2. Включите `Режим разработчика`.
3. Нажмите `Загрузить распакованное`.
4. Выберите папку, в которой находится этот README и `manifest.json`.
5. Откройте панель расширения:
   - добавьте локальный user token, если нужен оригинальный репост/чтение постов;
   - добавьте ID и токен каждого целевого сообщества;
   - настройте Render URL и `API_SECRET`.
6. Обновите уже открытые вкладки VK клавишей F5.

Токен сообщества создаётся администратором в управлении нужным сообществом, в
разделе работы с API/ключей доступа. Для копирования постов с фотографиями нужны
права на стену и фотографии. Не используйте один ключ как «общий» для другой
группы.

По умолчанию копирование использует токен сообщества. Если конкретное сообщество
не разрешает `wall.post` или загрузку фото этим токеном, в списке токенов нажмите
`Пост: группа`, чтобы переключить его на `Пост: user`. Комментарий всё равно
будет выполняться токеном сообщества.

## Проверка

```powershell
npm run verify
```

Тесты не отправляют запросы в VK и не требуют настоящих токенов. Реальный первый
smoke test нужно сделать вручную: одна тестовая группа, сначала текст, затем одно
фото. После публикации откройте фото и убедитесь, что владельцем указана тестовая
группа, а не паблик-источник. Затем проверьте отложенный комментарий.

## Ограничения safe-версии

- водяные знаки пока отключены: обработанные локальные файлы не сохраняются в
  восстанавливаемой очереди расширения;
- Клипы зависят от текущей разметки формы VK. При её изменении вкладка остаётся
  открытой, а очередь ставится на паузу для ручной проверки;
- Истории доступны только сообществам, которым VK разрешает их публикацию;
- файлы Историй ограничены 25 МБ, а ссылки-кнопки — внутренними HTTPS-ссылками VK;
- `wall.repost` требует локальный user token;
- поддержка `wall.post` и `photos.saveWallPhoto` токеном сообщества зависит от
  разрешений конкретного сообщества; для него предусмотрен явный режим
  `Пост: user`.
