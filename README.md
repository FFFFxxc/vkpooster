# VK Reposter Pro 4.5.0

Расширение для последовательной публикации в сообщества VK, отложенных постов,
комментариев и Историй, загрузки Клипов, аналитики и управляемой очистки данных.

## Главное в 4.5.0

- один подключённый пользовательский токен используется для постов, фото,
  репостов, комментариев, Историй и аналитики;
- интерфейс и режимы токенов сообществ временно отключены;
- отложенный пост передаётся на ваш Render и хранится в MongoDB только вместе с
  AES-256-GCM-шифротекстом токена;
- в назначенную минуту сервер читает исходный пост, заново загружает его фото в
  каждое целевое сообщество и выполняет `wall.post` без `publish_date`;
- поэтому время фотографии в просмотрщике VK совпадает с фактическим выходом, а
  Chrome и компьютер на момент публикации не требуются;
- комментарий к опубликованному посту создаётся сервером тем же пользовательским
  токеном и с устойчивым ключом идемпотентности;
- публикации по пабликам выполняются последовательно, минимум через 15 секунд;
  заданный в окне постинга интервал между группами сохраняется сервером;
- защитные ответы VK (CAPTCHA, validation, flood-control и suspicious activity)
  ставят задание на паузу вместо быстрого повторения;
- серверные посты, комментарии и Истории видны в общей отложке, их можно
  отменить, повторить после ошибки и очистить из MongoDB;
- карточка «Ожидания» хранит черновик: паблики, время, режим, текст и комментарий;
  исходная запись открывается отдельной кнопкой прямо на стене VK;
- выбор пабликов можно сохранять локальными наборами («Группа 1», «Группа 2»);
- копирование фото использует только свежие `owner_id`/`id`, возвращённые
  `photos.saveWallPhoto`, поэтому просмотрщик не ведёт к паблику-источнику;
- Клипы остаются локальным процессом в одной обычной видимой вкладке VK;
- TwiBoost, экспорт/импорт настроек, очистка стен/альбомов и аналитика сохранены.

## Установка расширения

1. Откройте `chrome://extensions` и включите режим разработчика.
2. Нажмите **Загрузить распакованное** и выберите папку с `manifest.json`.
3. Откройте VK Reposter Pro и подключите пользовательский токен.
4. Нажмите **Обновить список из VK**.
5. Укажите HTTPS URL Render и тот же `API_SECRET`, который настроен на сервере.
6. Нажмите **Сохранить и проверить**, затем обновите открытые вкладки VK.

Для автоматизации при выключенном компьютере Render должен оставаться активным.
Blueprint использует план `starter`: засыпающий web service не исполняет таймеры,
пока его не разбудит внешний запрос.

## Отложенный пост

1. В окне публикации включите отложку, выберите дату, время и интервал.
2. Расширение отправит на сервер только ID исходного поста, настройки задания и
   пользовательский токен по HTTPS; токен сразу шифруется `TOKEN_ENCRYPTION_KEY`.
3. До нужного времени фотографии не загружаются в VK.
4. В нужную минуту Render публикует пост по пабликам последовательно.
5. Если указан комментарий, сервер ставит его в собственную очередь 24/7.

## Ожидания

У записи из списка ожиданий автоматически сохраняются выбранные сообщества,
режим копии/репоста, текст, комментарий и локальная дата. Окно можно закрыть и
вернуться позже. Кнопка **Открыть исходный пост в VK** открывает оригинал.

## MongoDB и Render

Пошаговая инструкция: [server/README.md](server/README.md).

Blueprint: [render.yaml](render.yaml).

Коллекции создаются автоматически. Завершённые задания имеют TTL, а кнопка
**Очистка данных** удаляет ошибки, успешную историю либо всю завершённую историю,
не затрагивая активные задания.

## Проверка

```powershell
npm run verify
```

Тесты не обращаются к VK и не используют настоящие токены. После деплоя сделайте
smoke test на одном тестовом сообществе: текст, одно фото, отложенный пост и
комментарий. В `/health` должна отображаться версия сервера `4.3.0`.
